# Contributing to ZiloMentor Pro

Thanks for considering contributions. This is a GPLv3-or-later fork of
PRO Elements and retains notices for Elementor Ltd. and PRO Elements.

- Target changes to separate branches and submit pull requests.
- Do not change WordPress theme files to conceal incompatibilities.
- Preserve public Elementor Pro compatibility classes and stored widget IDs.
- Include regression tests for each compatibility change.
- Never add commercial subscription-token spoofing or remote licence
  validation interception.
- Do not include proprietary themes, customer databases, tokens or credentials.
- Keep documented attribution for modified GPL source.
- Never publish a release automatically from an unreviewed git tag.
